Introduction to HTML

The foundational language for building and structuring web pages

What is HTML?

HTML (stands for HyperText Markup Language) is the standard markup language for creating web pages. It defines the structure and layout of content using various tags.

Key Basic Tags

  • <h1> to <h6>: Defines headings at different levels.
  • <p>: Creates a text paragraph.
  • <a>: Creates hyperlinks.
  • <img>: Embeds images.
  • <div>: Acts as a container for grouping and structuring elements.

Basic HTML Document Structure

Every standard HTML document consists of the following skeleton:

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>This is the page content.</p>
  </body>
</html>
